🔍 Diagnostic Information

⚠️ Browser Crawler Limitations

This tool works best for testing small sections of the website. Browser-based crawlers face CORS restrictions that can cause failures.

If you experience failures:

  • Check the Activity Log for specific errors
  • Try the "Direct Mode" (no CORS proxy - may fail on some sites)
  • Reduce "Max Pages" for testing
  • For production work: Use the Python version

🚀 Quick Start

Example URLs to try:
• https://uidai.gov.in/en/ - UIDAI website
• https://example.com/ - Any website homepage
• https://docs.python.org/3/ - Python documentation

Tips:

  • Start with Max Pages = 20-30 for testing
  • The crawler automatically finds all linked pages
  • URLs must include http:// or https://
  • Trailing slashes are handled automatically
